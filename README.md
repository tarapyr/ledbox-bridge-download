# LEDBOX Bridge

**LEDBOX Bridge** je aplikace pro Windows, která zajišťuje přenos údajů z webové aplikace **eZápis** do zobrazovacího zařízení **TECH4SPORT LEDbox**.

Aplikace přenáší zejména:

* aktuální skóre,
* označení podávající strany,
* oddechové časy,
* střídání stran,
* výsledky setů a další události zápasu.

Řešení se skládá z aplikace LEDBOX Bridge pro Windows a rozšíření pro prohlížeč Google Chrome.

## Stažení

Aktuální verzi aplikace stáhnete zde:

### [Stáhnout nejnovější verzi LEDBOX Bridge](https://github.com/tarapyr/ledbox-bridge-download/releases/latest)

Na stránce vydání otevřete část **Assets**, kde najdete instalační program, dokumentaci a další soubory.

Pro stažení není nutný účet na GitHubu.

## Obsah vydání

Jednotlivá vydání mohou obsahovat:

* instalační program `LEDBOXBridge_Setup_*.exe`,
* uživatelskou příručku ve formátu PDF,
* rozšíření pro Google Chrome,
* ukázkové nebo instruktážní video,
* kontrolní součet instalačního souboru.

## Systémové požadavky

* operační systém Windows 10 nebo Windows 11,
* webový prohlížeč Google Chrome,
* zařízení TECH4SPORT LEDbox,
* připojení počítače a LEDboxu podle pokynů v uživatelské příručce.

Google Chrome je oficiálně podporovaný prohlížeč. Použití v Microsoft Edge může být možné, ale není primárně podporováno.

## Instalace

1. Otevřete stránku [nejnovějšího vydání](https://github.com/tarapyr/ledbox-bridge-download/releases/latest).
2. V části **Assets** stáhněte instalační soubor s příponou `.exe`.
3. Spusťte stažený instalační program.
4. Postupujte podle pokynů instalačního programu.
5. Proveďte nastavení aplikace, rozšíření prohlížeče a připojení LEDboxu podle uživatelské příručky.

Protože instalační program nemusí být opatřen komerčním digitálním podpisem, může systém Windows při prvním spuštění zobrazit upozornění **Windows chránil váš počítač**. V takovém případě zvolte **Další informace** a následně **Přesto spustit**.

Instalační program stahujte pouze z tohoto oficiálního repozitáře.
